FIRST LIGHT - IGNITE DEMO

An original 16-bar arrangement at 112 BPM in A minor:
01 Intro / 02 Groove / 03 Lift / 04 Outro (four bars each).

Five parts: drums, finger bass, electric piano, marimba arpeggio and square lead.
Use a General MIDI SF2 with bank 0 programs 4, 12, 33 and 80 (zero based),
plus bank 128 program 0 for drums. The MIDI contains no samples.

In IGNITE: Desktop Settings > SoundFonts > choose a GM SF2 > Set as default.
Then Projects > Create demo song. Close Settings and press Space / PLAY.
Save current edits and stop playback before creating the demo.
The demo is added to your library; existing songs are kept.

The bundled MIDI can also be imported using Import MIDI song in IGNITE or
opened in another DAW. Regenerate it with scripts/make-demo-midi.py.
